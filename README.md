## 📌 Sobre o Projeto

O projeto consiste em uma landing page moderna e altamente interativa para apresentar o lançamento do GTA VI. Ela conta com animações dinâmicas que reagem ao *scroll* do usuário, integração de vídeo de fundo, design estilizado e estrutura totalmente responsiva.

---

## ✨ Funcionalidades

- **Animação Interativa no Scroll**: Efeito de revelação da capa e sincronização do vídeo ao rolar a página utilizando GSAP e ScrollTrigger.
- **Menu Dinâmico**: Oculta/exibe a barra de navegação superior automaticamente conforme a rolagem.
- **Efeito de Revelação (Fade-In)**: Elementos surgem suavemente quando entram na área de visão (*viewport*).
- **Design Responsivo**: Adaptado para telas de computadores, tablets e smartphones.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, layout flexível (Flexbox), efeitos visuais e responsividade.
- **JavaScript (ES6+)**: Lógica de interação com o DOM, controle de vídeo e scroll.
- **GSAP (GreenSock Animation Network) & ScrollTrigger**: Biblioteca avançada de animação utilizada para sincronizar o vídeo de capa e elementos visuais com a rolagem.
- **Intersection Observer API**: Para disparar animações de entrada de elementos à medida que aparecem na tela.
